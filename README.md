# 🏯 AnimeVault

O **AnimeVault** é um gerenciador de animes local, desenvolvido para organizar suas coleções de forma visual, intuitiva e moderna. Com ele, você pode mapear suas pastas de episódios, acompanhar seu progresso e buscar informações detalhadas via integração com API.

## ✨ Funcionalidades (v1.0)

- **Organização Visual**: Visualize sua biblioteca com capas e títulos organizados em uma grade responsiva.
- **Mapeamento de Pastas**: Selecione a pasta local onde estão seus episódios e o app os lista automaticamente.
- **Busca Inteligente**: Integração com a API Jikan (MyAnimeList) para buscar capas, sinopses e gêneros.
- **Controle de Progresso**: Marque episódios como "vistos" para nunca se perder na história.
- **Tradução Integrada**: Opção para traduzir sinopses para o português.
- **Customização**: Adicione, edite ou remova animes da sua grade conforme sua preferência.

## 🛠️ Tecnologias Utilizadas

* [Electron](https://www.electronjs.org/) - Framework para apps desktop cross-platform.
* [Node.js](https://nodejs.org/) - Ambiente de execução JavaScript.
* [JavaScript/HTML5/CSS3] - Core do desenvolvimento do frontend.
* [Jikan API](https://jikan.moe/) - API aberta do MyAnimeList.
